Journal of Disquiet

Interview experience

I finally gave the interview for Python developer role at OpenCraft yesterday, after postponing it earlier for a week. I answered questions posed by Raul Gallegos, the interviewer. Raul asked me about my contribution to open source communities, challenges in previous roles and how I dealt with it. He then went on to the coding part where he asked me to write a Python program to add integers in a file and return their average. A simple program. I hadn’t used Python for quite some time and wasn’t aware of the file operations. So, I had to do an online search to find out the function for it and also how to read lines in a file. Raul asked me to share the web browser window (used for searching) along with the IDE. By the way the whole meeting was on Zoom and was being recorded by him. I started writing the program, modifying it and trying to get the needed output. Raul reminded me that I had only fifteen minutes to complete this task. I hurried and copied code snippets from the StackOverflow.com and used it in the program. I managed to get the result that he had asked for. I printed the average in the function, but he wanted me to return the average, so I had to change the program slightly. Then he moved on to the supposedly difficult part, the subsequent follow up question, which was based on recursion. Recursion is a technique used in computer science to build elegant solutions for problems involving repetition. Although, it is quite easy to implement but it is difficult to actually understand. So the question was to read the file for integers calculate the average but if there was a filename instead of the integer, then, that file should be read and the integers in it should be considered and so on, recursively. I was supposed to modify the existing solution written using an iterative loop to make it work for a recursive function call. I have not written a recursive function ever, in my experience, as part of any software that has gone into production. I had forgotten the concept of recursion and how to write one. It basically involves a base case and an inductive step. I had forgotten that recursion is actually induction: mathematical induction to be precise. The time was running out and Raul said this job is for someone who has Python development experience and ended the call. Post the interview, I was shocked, angry and irritated. I was shocked because I couldn’t write a recursive function, that is one of the fundamental concepts in computer science, and having studied it for four years I couldn’t do that. I felt, “How can I call myself a software engineer, if I don’t know recursion?”, “I had even taught a thirteen year old kid recursion once as part of online tutoring, and now in an interview I struggle myself to write one”, “Why didn’t I prepare well enough for this interview despite having over a week’s time?”, “Why of all the things was the interviewer interested in recursion? One that is used so infrequently” and so on. I tried to distract myself from these thoughts and went on to watch Slavoj Zizek’s funny videos online. I couldn’t sleep well and woke up early. The next day I slept during evening.
