Journal of Disquiet

Daily entry

I still find it hard to convince myself that I need to work for someone else for the sake of money. It’s hard to believe that I have to exchange my services for earning money and then use that money to avail other services or buy things that I am supposed to have. This is a huge hindrance for me in finding a software job. Why do I find myself so lazed out and unwilling to work towards a job or at least create a software project of my own? I sometimes wonder what is that software which is so necessary and that’s already not available there, that I should be putting my energies in building? I am unwilling to do even simple things such as flashing a BIOS using an external programmer. I keep asking the ’Why’ questions recursively and I end up not answering that the question which leads me to stop doing what I wanted to do. For example: “I want to revive my old desktop by re-flashing the bricked BIOS” “But, why do you want it to be in working condition anyway?” “Because it will be useful for doing stuff on it” “Like what? running a server, or donating it to others, wasting electricity by running a junk that’s decade old?” “I want to access the contents of the old fat HDD that’s lying around I can’t do that without the old motherboard” “Why don’t I buy an adapter to access the contents instead? Well that’s waste of money isn’t it buying thing that are unnecessary, instead of fixing things using items that are already available?” “To flash that, I will need Windows 7, another OS. I’ll have to format the existing HDD on the laptop, install Windows 7 because the BIOS software for some reason prefers Windows over the Linux counterpart” “That’s crap, I can’t get rid of this OS with all the files and installations just to get a BIOS flashed. What’s in that old HDD anyway that you so dearly want?” “I don’t know. Only when I access it that I will be able to look at the contents.” “For some reason, I want to try using that CH341a programmer, I suspect it doesn’t work at all. But I still want to make it work.”
