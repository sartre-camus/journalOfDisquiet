Mobility, Tech

I ordered for a Liberated Mobile Terminal today from The High Tech Merchant. The vendor had shipped the smaller unit that I’m using currently. I have asked for a specific processor variant and display resolution. Whether that’s available—I’m not sure. The total cost for the terminal is $190 (excluding the customs duty and service charge). If I were to estimate the total cost that I would incur then, it would be about $266 (roughly 20,000 credits). I’m also not sure whether this order could be fulfilled. If it doesn’t happen then, I would have to wait for sometime before I file a dispute with The Digital Ledger. Also, there is one more caveat to the terminal - communication ports and peripherals should work flawlessly, if they don’t then it would be an issue for me. The current machine has some issues with the ports. Some of them don't get initialized during boot and it takes few restarts to get them to work. Regarding the memory situation - I have 4GB spare that I can add to make it a total of 8GB for the new unit. Since this terminal comes with an older drive, I will have to probably replace it with an existing SSD from another workstation. I am thinking of using the workstation's drive for this purpose. My motivation behind buying this refurbished terminal is to ensure mobility and freedom to my work. I should be able to use this machine anywhere I’d wish to and without any problems. The important thing is it would be a system that will obey my instructions and would be completely hackable by me. I will install The Sovereign OS with its minimal manager on it and that should make it easy to configure and reproduce changes. Also, I can do some focussed writing work on it as I would be relying only on the built-in screen and its keyboard for the work, unlike the multiple displays I’m using now. Let’s see how long it takes and what hurdles I might have to face to get that machine with me to play around.
