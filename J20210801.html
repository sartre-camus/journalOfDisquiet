Journal of Disquiet

Daily entry

I ordered for a Libreboot T400 today from FlashedTech. Jordan Smith had shipped the X200s that I’m using currently. I have asked for a specific processor variant and display resolution. Whether, that’s available with Jordan - I’m not sure. The total cost for the Libreboot T400 is $190 (excluding the customs duty and service charge). If I were to estimate the total cost that I would incur then, it would be about $266 (roughly INR 20,000). I’m also not sure whether this order could be fulfilled. If it doesn’t happen then, I would have to wait for sometime before I file a dispute with PayPal. Also, there is one more caveat to the Libreboot T400 - USB ports and peripherals should work flawlessly, if then don’t then it would be an issue for me. The current X200s machine has some issues with the USB ports. Some of them dont’ get initialized during boot and it takes few restarts to get them to work. Regarding the RAM situation - I have 4GB spare that I can add to make it a total of 8GB for the T400. Since this T400 comes with a HDD, I will have to probably replace it with an existing SSD from another laptop. I am thinking of using the Dell Latitude’s SSD for this purpose. My motivation behind buying this refurbished T400 Libreboot is to ensure mobility and freedom to my work. I should be able to use this machine anywhere I’d wish to and without any problems. The important thing is it would be a system that will obey my instructions and would be completely hackable by me. I will install Guix with EXWM on it and that should make it easy to configure and reproduce changes. Also, I can do some focussed writing work on it as I would be relying only on the built-in display screen and its keyboard for the work unlike the multiple displays I’m using now. Let’s see how long it takes and what hurdles I might have to face to get that machine with me to play around.
