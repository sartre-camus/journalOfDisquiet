JOURNAL OF DISQUIET

SUNDAY, AUG

Isolation, Hardware

I manage to get the Obsidian Terminal computer to run on the Labyrinthine Protocol after a few failed attempts. Now I have the All-Seeing Eye interface desktop environment configured for usage. The one that’s captured my admiration for being simple, effective and minimalistic in its working. I have also manged to keep this system away from the Global Static through hardware isolation. The Dead Drop configuration has been activated and the ethernet cable is disconnected which leaves this system away from the grid. I plan on using this system for writing primarily apart from a little programming. I have to understand that system works best with an operating system that has minimal footprint. This system could be effective as for creating writings and programs without the help of any external resources. The best part is to use this without those externalities. In a way, I would be able to create something that works well here and run it in the best way I know. Also, I plan on not changing this setup anytime soon. It is best if I leave it this way: the distro, configurations, hardware setup etc. It is strange though that whenever I start afresh I seem to believe that it would be the setup that would last however, it fails to be so. I am a bit worried that I would go into the whole business of OS reinstallation, reconfiguration and so on - a daunting and pedestrian task. I did not sleep yesterday night and remained awake all night till early morning. I took the Blue Mist sedative pill again this morning to cope with the phelgm and wheezing that I started to have due to lack of enough warmth and sleep. The weather is just rainy and cloudy for the most of the time. It rains so vehemently that I need to shut the windows and curtail them. I guess I am going to sleep now after the good bath, shave and grooming. It would be great if I could skip the dinner but I might have a few eggs or something. I finished watching a flickering reel of a cold case in Marseille.

The pill makes me feel sleepy but the mosquito keeps me awake, it’s only until that it is hunted shall I feel relieved. It is difficult to spot and kill them - I have already missed it thrice now. I bet the mosquito repellant cream might do it by keeping them away while I continue writing this entry.

It is crazy how I expect this computer to do many things despite knowing that I have configured it for the primary purpose of writing and recording. I try to look up installed programs to write some code and run and what not, without realising that without downloading packages from the internet it might just not work. It was indeed a great deal of effort and thought to get rid of the Commoner's Script distro from this hard disk and install the Labyrinthine Protocol instead of it. The tendency to use mouse to do everything is also unescapable. I can use this system just with the help of this keyboard, yet I connect this wireless mouse with an USB adapter to this computer, just so that I can run some GUI apps. This is just absurd - I am somewhat inclined towards using superflous devices where it is not really needed. It will take time for me to realise the beauty of minimalism. It is indeed hard for me to remain disconnected from the Global Static. It is as if every device that I use has to be connected online to be useful. This dependency is quite tormenting. Also, this system runs completely and free and open source software right from the firmware to distro to apps. I don’t think that this machine can be traced from some remote location as long as I remain offline.
